## Pet-проекты

### Marketplace Sales Analysis

Анализ данных маркетплейса: заказы, выручка, категории товаров, доставка, отзывы клиентов и продавцы.

**Что сделано:**
- очищены и подготовлены данные;
- рассчитаны ключевые метрики: выручка, количество заказов, средний чек, доля поздних доставок;
- проведён EDA;
- построены графики по динамике заказов, категориям и доставке;
- сформулированы бизнес-выводы и рекомендации.

**Стек:** Python, pandas, SQL, Matplotlib, Seaborn

---

### Customer Churn Analysis

Анализ оттока клиентов: поиск групп пользователей, которые чаще прекращают пользоваться продуктом.

**Что сделано:**
- рассчитан общий churn rate;
- проведена сегментация клиентов;
- проанализирована связь оттока с типом договора, платежами и другими признаками;
- построены визуализации;
- проведена базовая статистическая проверка;
- сформулированы рекомендации для удержания клиентов.

**Стек:** Python, pandas, NumPy, SciPy, Matplotlib, Seaborn

---

### A/B Test Conversion Analysis

Анализ результатов A/B-теста для проверки изменения конверсии между контрольной и тестовой группами.

**Что сделано:**
- проверено качество данных эксперимента;
- рассчитаны конверсии по группам;
- сформулированы гипотезы H0 и H1;
- проведён статистический тест;
- рассчитан uplift;
- сделан вывод о том, можно ли раскатывать изменение.

**Стек:** Python, pandas, SciPy, statsmodels, Matplotlib
